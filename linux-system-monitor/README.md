#Linux system monitor
##Description
un outil python permettant de surveiller les resources d'un système linux
##Fonctionnalités
-informations sur le systeme
-utilisation du processeur
-surveillance de la mémoire RAM
-Espace disque disponible
##Technologies
-Python 3
-Linux Ubuntu
-Git et Github
-Bibliothèque psutil
##Exécution
python3 monitor.py
